Un post de ejemplo con **imagen de portada** y fecha de actualización, para validar que el artículo muestra todo el sistema: hero, metadatos, contador de vistas y Open Graph.

## Dos cuadernos, un escritorio

La idea de este sitio es simple: un cuaderno donde la **tecnología** (desarrollo web, infraestructura, herramientas) y la **teología** (estudio bíblico, lenguas originales) conviven sin competir.

## Qué valida este post

- Imagen de portada procesada en el build (`heroImage`).
- Fecha de publicación y de actualización con formato local `es-CL`.
- Contador de lecturas servido por una Server Island desde KV.
- Banner OpenGraph generado con Satori: comparte esta URL en cualquier red y verás la tarjeta.
